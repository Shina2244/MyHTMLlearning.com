HTML Forms kya hote hain?

👉 Form ek section hota hai website pe, jisme user input deta hai. Jaise:

  • ✔ Login Form
  • ✔ Search Box
  • ✔ Contact Form
  • ✔ Signup Form

Ye input server ko bheja jata hai backend processing ke liye.

Form ka Basic Structure

<form action="" method="POST"></form>

<form>: Ye form ka container hota hai.
✔ action: Kis page ya script pe data bhejna hai (e.g. PHP file).
✔ method: Kaunsa HTTP method use karna hai - usually GET ya POST.

Common Form Elements

a) <input>

Ye user input ke liye use hota hai.

<input type="text" name="username" placeholder="Enter your name">

  • type: kaunsa input (text, password, email, etc.)
  • name: backend ko data bhejne ke liye
  • placeholder: user ke liye hint
<textarea>

Jyada text lene ke liye use hota hai (e.g. feedback ya comment box).

<textarea name="feedback" rows="4" cols="30"></textarea>

<select> (Dropdown)

<select name="city">
  <option value="delhi">Delhi</option>
  <option value="mumbai">Mumbai</option>
</select>

Radio Buttons

<input type="radio" name="gender" value="male"> Male
<input type="radio" name="gender" value="female"> Female

Male Female
Checkboxes

<input type="checkbox" name="hobby" value="cricket"> Cricket
<input type="checkbox" name="hobby" value="music"> Music

Cricket Music
Password Field

<input type="password" name="userpass">

Submit Button

<input type="submit" value="Submit">

Method: GET vs POST

Method Description Data Size Security
GET URL me data dikhai deta hai (visible) Small data (search) Less secure
POST Data hidden hota hai Large data (login, signup) More secure

🟦 Summary:
HTML forms ka kaam – user ka data lena & backend ko bhejna.
Forms me input, textarea, select, button sab milke form banate hain.
Aur action & method se decide hota hai ki data kaise backend tak jaye.
