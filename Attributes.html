🔍 HTML Attributes Explained

Definition: Attributes HTML elements ko additional information dete hain, jisse browser ya user ko aur context milta hai.

Example: <img src="dog.jpg" alt="Dog Photo" width="250">

  • src: Image ka source (file path ya URL)
  • alt: Alternative text (jab image load na ho)
  • width: Image ki width in pixels

⚡ Attributes har element ke behavior aur display ko control karte hain.
Jaise: href in <a>, type in <input>, class, id, style etc.
