<table> tag ka use?

➡ Table tag ka use hum kisi bhi data ko table format mein dikhane ke liye karte hain. Jaise ki rows aur columns ke form mein data dikhana ho.

  • <table> - Table tag
  • <tr> - Row banane ke liye
  • <td> - Data cell ke liye
  • <th> - Heading ke liye
